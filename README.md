# Tkinter Calculator

This is a simple and user-friendly calculator built using Python's Tkinter library. The calculator allows you to perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features
- **Basic arithmetic operations:** Add, subtract, multiply, divide.
- **Clear button:** Resets the current input and result.
- **User-friendly interface:** Designed with Tkinter to provide a simple and intuitive GUI.

## Requirements

- Python 3.x
- Tkinter (usually bundled with Python installations)

## Installation

1. **Clone the repository**:
    ```bash
    git clone https://github.com/duroblackbro/calculator_using_tkinter
    ```
   
2. **Navigate to the project directory**:
    ```bash
    cd tkinter-calculator
    ```

3. **Run the calculator**:
    Simply run the Python script:
    ```bash
    python calculator.py
    ```

## Usage

- Open the calculator window by running the script.
- Use the number buttons to input digits.
- Use the operator buttons to perform arithmetic operations.
- Click `C` to clear the current input.
- Click `=` to see the result of the operation.
  
## Code Overview

The calculator application is built using Python's Tkinter library. Below is a brief overview of the key components of the code:

- **Button Widgets**: The calculator's number buttons and operators are created using Tkinter's `Button` widget.
- **Entry Widget**: The `Entry` widget is used to display the current input and result.
- **Functionality**: The program defines functions for performing arithmetic operations and updating the display.
